# MedMemory MCAT — Interactive MVP

This version expands the original prototype into an active-learning medical/MCAT study site.

## Included modules
- Glycolysis: all 10 pathway positions, enzymes, ATP/NADH accounting, regulation, irreversible steps, anaerobic lactate
- Krebs/TCA cycle: sequence, enzymes, NADH/FADH2/GTP/CO2 yield, location, ETC connection
- ETC + oxidative phosphorylation: complexes, electron flow, proton pumping, oxygen, ATP synthase
- Nucleic acids: purines/pyrimidines, base pairing, replication, transcription, translation
- Protein structure & enzymes
- Genetics & gene expression: central dogma, PCR, mutations, RNA processing
- Carbohydrate metabolism: insulin/glucagon, glycogen, gluconeogenesis, PPP

## Interactive learning modes
1. Learn — visual mental map + high-yield facts
2. Build the Pathway — reconstruct sequence from shuffled concepts
3. Sort the Facts — classify concepts/processes
4. Free Recall — blank-page retrieval before revealing checklist
5. Challenge Questions — application questions with explanations
6. Speed Round — rapid retrieval

Progress and mastery are stored locally in the browser.

## Put it on GitHub Pages
Upload `index.html`, `style.css`, and `app.js` to your repository. Enable GitHub Pages from repository Settings → Pages, selecting the branch/folder containing these files.
